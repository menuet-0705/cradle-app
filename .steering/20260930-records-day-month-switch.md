# 20260930 記録タブの「日｜月」切り替え

## 要望
- 「カレンダーで見る」（日付の見出しをタップして別画面を開く）がわかりづらい
- 日と月を、切り替えスイッチで選べるようにする

## 方針
- 記録タブの一番上に「日｜月」の切り替え（SegmentedButton）を置く
  - 日: これまでの 1 日ごとの記録一覧（◀ 日付 ▶・スワイプ）。日付の見出しは普通の文字に戻す（カレンダーのボタンはやめる）
  - 月: 記録タブの中に月間カレンダーを出す（別画面は開かない。`/records/calendar` の画面・ルートはなくす）
- 月で日付をタップすると、下にその日の要約が出る（これまでと同じ）。「この日の記録を見る」で「日」に切り替わり、その日を出す（確認済み）
- カレンダーで選んでいる日 = 記録画面で選んでいる日（`selectedDayProvider`）にそろえる
  - 月に切り替えたときは、日で見ていた日の月を出し、その日に選択の印を付ける。詳細カードは日付をタップしてから出す（最初から出すと、月のまとめが画面の下に押し出されるため）
  - 右下の＋は、月表示でもカレンダーで選んでいる日に記録を追加する
- どちらを表示しているかは、グラフ・AI のタブへ移って戻っても保つ（ログアウトで日に戻る）
- 読み込み中の見せ方（進捗バー・仮の棒・「読み込み中…」）はこれまでと同じ

- [x] カレンダー: 別画面をやめて記録タブに埋め込むウィジェットにする。選んでいる日を selectedDayProvider にそろえる

- [x] テスト更新: 切り替えで月・日を行き来、月で日付を選んで「この日の記録を見る」で日のその日へ、月で選んだ日に＋で追加、タブを移っても表示を保つ
- [x] 検証: `flutter analyze` / `flutter test`

## 実装メモ（計画からの変更）
- カレンダーのファイルを `records_calendar_screen.dart` から `records_calendar_view.dart` に改名（画面ではなく記録タブに埋め込む部品になったため）
- 以前の `/records/calendar` は、履歴・ブックマークから開かれたときのためにホームへ転送するだけのルートとして残した
- 月の表示のまま月をまたいでアプリに戻ったら、新しい今月を基準に作り直す（日の表示の「0 時をまたいだら作り直す」と同じ考え方）
- こどもを切り替えたら、カレンダーを作り直す（生まれた月までのページ数がこどもごとに違うため）
- 日の表示でさかのぼれる日（3650 日前）より前は、カレンダーでも選べない（`recordsMaxPastDays` を共有）
- 切り替えボタンにツールチップ（1日ごとの記録／カレンダー）

## 検証
- `flutter analyze` 問題なし、`flutter test` 75 件成功
  - 切り替えで月・日を行き来し、日で見ていた日の月から始まる／月で選んだ日に＋で追加／タブを移っても表示を保つ／ログアウトで日に戻る／詳細カードはタップしてから出る
- API の変更はなし

## レビュー結果
code-reviewer・security-reviewer とも Critical・High なし。

### 対応したもの
- Medium: 月の表示のまま月をまたぐと今月へ進めない → アプリに戻ったときに今月を確かめて作り直す
- Medium: 月の表示にしただけで詳細カードが出て、月のまとめが押し出される → 詳細カードはタップしてから
- Low: 選んだ日が日の表示の範囲外になりうる、選んでいる日をタップしてもスクロールしない、古い URL、切り替えボタンの読み上げ、コメント、テスト不足
- Low（security）: 月の表示のままこどもを切り替えると、ページ数が前のこどものまま → こどもごとに作り直す

### 受け入れたもの（対応しない）
- Medium: 月の表示で、選んだ日と別の月を見ているとき、＋で追加する先が見えていない日になる。追加画面に日付が大きく出るので、そこで気づける
- スマホの画面では、カレンダーの下の「月のまとめ」はスクロールしないと見えない（切り替えボタン・月の見出し・6 行のマスで画面が埋まるため）
- 月の表示を開いたまま（アプリを裏に回さずに）月末の 0 時をまたいだときは、切り替え直すまで新しい月へ進めない
